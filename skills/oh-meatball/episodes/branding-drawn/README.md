## Upload (YouTube Studio, desktop)

1. **Banner:** studio.youtube.com → **Customization** → **Branding** tab → **Banner image** → **Change** → pick `banner.png` → check the preview for TV, desktop and mobile → **Done** → **Publish** (top right).
2. **Profile picture:** **Customization** → **Branding** → **Picture** → **Change** → `avatar.png` → **Done** → **Publish**.
3. **Watermark:** **Customization** → **Branding** → **Video watermark** → **Change** → `watermark.png` → **Display time**: *Entire video* → **Done** → **Publish**.
4. **Description:** **Customization** → **Basic info** tab → **Description** → paste the text below → **Publish**.
5. **Keywords:** **Settings** (bottom left) → **Channel** → **Basic info** → **Keywords** → paste the list below → **Save**.

TikTok app: **Profile** → **Edit profile** → **Change photo** → `avatar.png`, then **Bio** → paste the bio below → **Save**.
