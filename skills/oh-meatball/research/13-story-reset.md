# 13 — Story reset (2026-10-19, after Nolan: "no tags and story actually sucks")

## What was wrong
- **Story:** a serialized twist pile (wedding objection → secret marriage → kitten → secret brother → twin → will).
  Every part needs the previous ones; a new viewer understands nothing. Breakouts in this niche are ONE simple
  emotional arc per video (research/10): setup → suffering → kindness/rescue → reversal → karma payoff.
- **Tags:** OpusClip schedule_publish never sends YouTube tags, so every Oh Meatball upload has 0 tags.
  vidiq_update_video can set them but YouTube asks Nolan for a one-time verification first.

## New format (replaces E5's "previously + new shots")
- Every video is a self-contained 56–64 s story (7–8 shots x 8 s). Same cast, new situation each time, like a sitcom.
- Arc: humiliation (frame 0) → kindness → sacrifice/comedy beat → big reveal → villain exposed → reward → mirror payoff
  (the opening insult flipped back on the villain). The last line echoes the first.
- Meatball = kind, poor, chubby hero. Rigatoni = rich snob villain who gets karma. Duchess = rich and kind.
  Pip = the kitten who needs rescuing. Grandma Shelly/Biscuit as helpers when useful.
- Proven trope bank: poor-to-rich, karma for a rude customer, lost-kitten reward, fake friend exposed,
  "they laughed at him / he got the last laugh", cheating partner with rich rival, kind act repaid 100x.
- Title: `[Kind act] … then [reversal] 😱 #shorts #catstory #oh meatball` style; describe the story, no "Part N".
- Hashtags go IN the title and description (#shorts #catstory #aianimation #ohmeatball) because tags don't transfer.
