# FurEver Faces: Etsy listings

Ready-to-paste text for 24 Etsy listings: six doodle designs on four products. Written 2026-11-14.

## How to use

1. In Printify, create the product with the design's print file and publish it to Etsy.
2. Paste the title, tags and description below into the Etsy listing.
3. On each listing, name Printify as the production partner and state that the artwork was made with AI tools.

Titles are under Etsy's 140-character limit. Each listing has 13 tags, none longer than 20 characters. Prices match the Shopify store; raise them if Etsy fees make the margin too thin.
