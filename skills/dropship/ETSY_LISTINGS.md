# FurEver Faces: Etsy listings

Ready-to-paste text for 24 Etsy listings: six doodle designs on four products. Modelled on the TuxedoAndTails shop as seen in a screen recording on 2026-11-14.

## What the reference shop does

- One breed, one look: five listings, all Boston terriers, all the same cartoon style.
- Tees first: four tees at $26.00 and one mug at $18.00.
- Real product photos: about ten images per listing, generated by Printify when the listing is published.
- Keyword titles: breed first, then the slogan, then who it is for.
- A delivery date on every listing, filled in by Etsy.

## How to use

1. In Printify, create the product with the design's print file from `fureverfaces/print/` and publish it to Etsy. Printify adds the product photos.
2. Paste the title, tags and description below into the Etsy listing.
3. On each listing, name Printify as the production partner and state that the artwork was made with AI tools.
4. Start with the six tees, then the six mugs.

Titles are under Etsy's 140-character limit. Each listing has 13 tags, none longer than 20 characters. Tee and mug prices match the reference shop; check Printify's cost plus shipping before publishing, because $26.00 leaves a thin margin if shipping is free.
