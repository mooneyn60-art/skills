# Venture protocol (paper first, like TARS's paper trading)

Every venture gets a row in VENTURES below with its test, kill and promote criteria fixed in
advance. Nobody moves the goalposts afterwards.

1. **Cheapest real test.** The smallest version that touches real buyers (10 listings, 1 landing
   page, 3 posts). Not a plan, a test.
2. **Kill criteria.** Written before launch. Hit them -> stop, log why, move the parts elsewhere.
3. **Promote criteria.** Written before launch. Hit them -> scale (more products, more posts,
   more agent time).
4. **Measure per unit of cost** (see RULES.md #5) and log money in/out in LEDGER.csv.
